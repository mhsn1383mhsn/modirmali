# نقشه پروژه (کدام پوشه = کدام بخش برنامه)

## بخش‌های داخل برنامه (فایل‌های www — اسم هر فایل = اسم همان بخش)
| فایل | بخش در برنامه | چه کاری می‌کند | توابع اصلی کد |
|---|---|---|---|
| `داشبورد.html` | داشبورد | جمع‌بندی صندوق‌ها، ثروت، اقساط و طلب/بدهی + درآمد/هزینه/پس‌انداز ماه + مصرف بودجه + تفکیک دسته‌ها + سررسیدهای نزدیک + آخرین تراکنش‌ها + کارت حساب گوگل | renderDashboard، monthIncomeExpense، monthExpenseByCategory |
| `صندوق.html` | صندوق | چند صندوق، ثبت ورود و خروج پول، مانده لحظه‌ای | renderFunds، fundBalance |
| `ثروت.html` | تخصیص ثروت | دسته‌های دارایی با درصد، تقسیم خودکار درآمد، برداشت | renderWealth، allocateBtn |
| `اقساط.html` | اقساط و وام | وام‌ها، قسط ماهانه، ثبت پرداخت و جریمه تأخیر | renderLoans، loanBalance |
| `اشخاص.html` | حساب‌وکتاب اشخاص | بدهکار/بستانکار هر شخص و تراکنش‌ها | renderPersons، personBalance |
| `چک‌ها.html` | مدیریت چک‌های بانکی | چک دریافتی/پرداختی، سررسید، وضعیت، خروجی CSV | renderChecks، addBankCheck، exportChecks |
| `بودجه.html` | بودجه | سقف ماهانه هر دسته + نوار پیشرفت رنگی + مجاز روزانه | renderBudgets، budgetDaysLeft |
| `درآمد-هزینه.html` | درآمد و هزینه | ثبت درآمد/هزینه با اتصال به صندوق + انتقال بین صندوق‌ها + فیلتر دوره/نوع/جستجو | renderCashflow، addIncomeExpense، addTransfer |

`www/index.html` نسخه کامل با نوار تب است؛ بقیه فایل‌ها با اسکریپت `scripts/build-focus-pages.py` از آن ساخته می‌شوند (بعد از هر تغییر در index.html اجرایش کن تا کپی‌ها کهنه نمانند — در CI هم خودکار اجرا می‌شود).

بخش «تنظیمات» (واحد پول، پشتیبان‌گیری JSON، خروجی CSV، حذف کامل داده) فقط در `index.html` از دکمه ⚙️ بالای صفحه است و صفحه تمرکز ندارد.

## بخش‌های مشترک داخل هر فایل (به ترتیب کد)
1. استایل و تم (CSS) — بدون تغییر نسبت به نسخه اولیه
2. ساختار صفحه (HTML) و صفحه ورود گوگل
3. تقویم شمسی و قالب اعداد فارسی
4. ذخیره‌سازی (State / localStorage)
5. نمایش هر بخش (render…)
6. فرم‌ها و دکمه‌ها (openFormSheet و رویدادها)
7. حساب گوگل و همگام‌سازی ابری (Supabase)

## پوشه‌های فنی (نام انگلیسی لازم است، چون ابزار ساخت اسمشان را می‌خواهد)
| پوشه | کار |
|---|---|
| `www` | خود برنامه |
| `supabase` | اسکریپت SQL جدول + راهنمای ورود گوگل |
| `scripts` | اسکریپت‌های ساخت |
| `keystore` | کلید امضای APK |
| `assets` | آیکون اصلی |
| `.github/workflows` | ساخت خودکار APK در GitHub |
| `docs` | راهنماها |
