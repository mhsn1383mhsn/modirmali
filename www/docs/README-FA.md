# مدیریت مالی — نسخه اندروید (APK)

همان `index.html` شما (بدون تغییر در تم و طراحی) + ورود با گوگل + ذخیره ابری (Firebase).

## امکانات (فاز ۱ سند طراحی)
- صندوق‌ها، تخصیص ثروت، درآمد/هزینه، اقساط، حساب‌وکتاب اشخاص، چک‌های بانکی
- **بودجه ماهانه دسته‌ها** با نوار پیشرفت رنگی (سبز/زرد/قرمز) و «مجاز روزانه تا پایان ماه»
- **اتصال تراکنش به صندوق**: هزینه/درآمد مستقیم از مانده صندوق کم/زیاد می‌شود؛ **انتقال بین صندوق‌ها** در گزارش درآمد/هزینه حساب نمی‌شود
- داشبورد: درآمد/هزینه/نرخ پس‌انداز ماه + مقایسه با ماه قبل، تفکیک دسته‌ها (کلیک = فیلتر)، سررسید چک‌های ۷ روز آینده، آخرین تراکنش‌ها
- تنظیمات ⚙️: تومان/ریال، پشتیبان‌گیری و بازگردانی JSON، خروجی CSV تراکنش‌ها، حذف کامل داده‌ها

## ساخت APK با GitHub
۱. یک مخزن جدید در GitHub بسازید و **همه محتویات این پوشه** را آپلود کنید (پوشه مخفی `.github` هم باید برود).
۲. تب **Actions** ← «Build Finance APK» ← **Run workflow**.
۳. بعد از ۵ تا ۱۰ دقیقه، از بخش **Artifacts** فایل `Finance-apk` را دانلود کنید و `app-debug.apk` را نصب کنید.

قبل از ساخت APK، ورک‌فلوی خودکار تست محاسبات مالی (`tests/selftest.mjs`) اجرا می‌شود و اگر خطا باشد ساخت متوقف می‌شود. فایل اصلی برنامه `www/index.html` است.

## ورود با گوگل
- Firebase همان پروژه `dayflow-2f339` است (فایل `firebase/google-services.json`) و شناسه برنامه `app.dayflow.planner` ماند تا ورود بدون تنظیم اضافه کار کند.
- در Firebase Console: Authentication ← Sign-in method ← **Google** را فعال کنید و Firestore Database را بسازید.
- قوانین پیشنهادی Firestore (هر کاربر فقط داده خودش):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
- برای اجرا در مرورگر (نه APK)، دامنه سایت را در Authentication ← Settings ← Authorized domains اضافه کنید.

## همگام‌سازی
هر تغییر پس از ۱.۵ ثانیه در Firestore ذخیره می‌شود؛ با ورود در دستگاه دیگر، داده همان حساب بارگذاری می‌شود.
